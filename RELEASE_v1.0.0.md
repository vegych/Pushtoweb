# 🚀 Release v1.0.0 — PushToWeb (SMS & Push to Telegram Gateway)

**Дата релиза:** 6 октября 2026  
**Тег:** `v1.0.0-stable`  
**Статус:** Production Ready  

---

## 🌟 Что нового в версии 1.0.0

Первый стабильный публичный релиз полноценной платформы пересылки сообщений:

### 1. Ядро пересылки и шлюз
- Встроенный сервер Express с поддержкой Webhook API и авторизацией по ключу `X-API-Key`.
- Полная интеграция с Telegram Bot API: поддержка форматирования HTML, беззвучного режима (`silent notification`), кастомных эндпоинтов и прокси.
- Антидубликатор: защита от повторной отправки одинаковых SMS/пушей при сетевых ретраях.

### 2. Фильтрация и антиспам
- Готовая база предустановленных правил для ведущих мобильных банков:
  - СберБанк (`ru.sberbankmobile`, короткий номер 900)
  - Т-Банк (`com.idamob.tinkoff`)
  - ВТБ (`ru.vtb24.mobilebanking`)
  - Альфа-Банк (`ru.alfabank.mobile.android`)
  - Райффайзенбанк (`ru.raiffeisennews`)
  - Госуслуги (`ru.rostel`)
- Фильтрация по черным/белым спискам, ключевым словам и RegEx регулярным выражениям.
- Специальный режим «Только 2FA»: пересылаются только сообщения, содержащие коды подтверждения.

### 3. Оформление сообщений
- Интеллектуальный анализатор текста для извлечения 4-8 значных кодов подтверждения (OTP/2FA).
- Автоматическое выделение кода в моноширинный тег `<code>`, поддерживающий копирование в буфер по нажатию в Telegram.
- 4 готовых стиля оформления:
  - **🌟 Классика** — сбалансированный стиль со всеми деталями.
  - **⚡ Компактный** — минимум строк, максимум плотности.
  - **🛡️ Только код** — отправка исключительно кода и отправителя.
  - **📋 Подробный** — полная информация со слотом SIM, временем и именем приложения.
- Поддержка двух SIM-карт с настраиваемыми именами операторов (МТС, билайн, МегаФон, t2).

### 4. Мобильная интеграция (Android OS)
- Нативный Kotlin-проект со службой `ForwarderForegroundService`.
- Постоянный наглядный индикатор в строке состояния Android:
  `🟢 Активен: SMS [ВКЛ] · Push [ВКЛ]`
- Автозапуск при включении устройства (`BOOT_COMPLETED`).
- Обход оптимизации батареи (Doze mode) для бесперебойной работы 24/7.
- Готовый шаблон для MacroDroid / Tasker для запуска без компиляции APK.

### 5. Панель управления и релизный хаб (3x-manager style)
- Раздел «Релиз и обзор v1.0.0» с интерактивной галереей экранов, чеклистом готовности и экспортом описаний для 4PDA, GitHub, Telegram и магазинов.
- Резервное копирование: экспорт и импорт полной конфигурации в JSON в один клик.
- PWA поддержка и адаптивный темный интерфейс.
