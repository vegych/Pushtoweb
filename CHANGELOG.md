# Changelog / История изменений

All notable changes to PushToWeb will be documented in this file.

## [v1.1.17] - 2026-10-09

### ✨ Что нового
- ⚠️ **Предупреждающая плашка**: Баннер об отсутствии доступа к уведомлениям отображается сразу при первой установке приложения, не дожидаясь включения сервиса.
- ⚙️ **Запрос разрешений**: Диалоги запроса прав (SMS, уведомления) перенесены исключительно на момент активации сервиса пользователем.
- 🏷️ **Динамическая версия**: Реальная версия приложения определяется из нативного Android пакета (`packageManager`), устраняя застрявшие значения версии.
- 📥 **Скачивание APK**: Кнопка «Скачать APK» в WebView корректно открывает прямую загрузку во внешнем браузере или системном загрузчике Android.
- 🔑 **Единый ключ подписи**: Настроен постоянный `release.jks` для бесшовной установки обновлений поверх старых версий без конфликтов подписи.
- 🚀 **Маркировка релизов**: Внедрена дифференциация версий — `X.1.0` (крупный функционал) и `X.X.1` (патчи и исправления).

## [v1.0.16] - 2026-10-07

### 🛠️ Изменения
- Добавлена автоматическая проверка обновлений через GitHub Releases API.
- Базовая интеграция Android-сервиса пересылки и веб-интерфейса PushToWeb.
